# AI音声対話デモ

音声認識（Web Speech API）・生成AI（Claude, sample capability if available）・音声合成（speechSynthesis）を
組み合わせた音声対話デモです。CrowdWorksの「AI音声システム統合開発」案件への応募用サンプルとして作成しました。

## 公開ページ
GitHub Pagesで公開: このリポジトリのPages設定を参照してください。

## 補足
- claude.aiのアーティファクトとして開く場合は、生成AI部分は実際のClaudeが応答しますが、
  アーティファクトのサンドボックスの制約でマイク入力は利用できません（テキスト入力で代替可能）。
- このGitHub Pages版は通常のWebページとして配信されるため、マイク入力が利用可能です。
  一方、生成AI部分はclaude.ai固有の機能を使えないため、デモ用の定型応答で動作します。
